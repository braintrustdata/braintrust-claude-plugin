# Go SDK

## Fetch Latest Version

Fetch `https://api.github.com/repos/braintrustdata/braintrust-sdk-go/releases/latest` and read `tag_name`

Or visit: https://github.com/braintrustdata/braintrust-sdk-go/releases

## Add to Dependencies

```bash
go get github.com/braintrustdata/braintrust-sdk-go@vX.Y.Z
```

## Verify Installation

Test that the SDK is installed:

```bash
go list -m github.com/braintrustdata/braintrust-sdk-go
```
