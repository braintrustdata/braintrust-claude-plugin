# Ruby SDK

## Fetch Latest Version

Fetch `https://rubygems.org/api/v1/versions/braintrust/latest.json` and read `version`

Or visit: https://rubygems.org/gems/braintrust

## Add to Dependencies

Add to `Gemfile`:
```ruby
gem 'braintrust', '~> X.Y'
```

## Install Command

```bash
bundle install
```

## Verify Installation

Test that the SDK is installed:

```bash
ruby -e "require 'braintrust'"
```
